# AGENTS.md - 戴南钢算AI（Argon 轻量化多智能体全量工程规范）

## 1. 项目定位与赛事要求
本项目参加泰州市2026年“全球通”杯人工智能OPC创新创业大赛（赛道二：行业轻量智能体开发赛道）。
核心目标：解决兴化戴南不锈钢产业带中小微加工企业“非标异形件看图算料慢、易算错、切割边角余料闲置”的痛点。

## 3. 三层解耦架构红线（Codex 必须严格遵守）
1. **数学运算与大模型绝对隔离**：所有重量、材料利用率、戴南下差折算、13%增值税专票换算、内孔圆芯回流估值及周边余料套切省钱金额，必须 100% 调用 `core/steel_engine.py`，严禁在前端或 Prompt 中自行拼接算术公式。
2. **三智能体标准流水线 (`core/agent_pipeline.py`)**：
   - `Agent 1 · 询盘解析风控员`：校验参数完整性，遇到漏标厚度（如 `TP-015.png`）立即返回 `NEED_INFO` 状态并生成地道戴南生意人微信追问话术。
   - `Agent 2 · 戴南资深核价师`：输出“方案A：理计不含税自提价”与“方案B：过磅含13%专票价”双轨报价单，内径 >= 80mm 时生成《内孔圆芯余料回血卡片》。
   - `Agent 3 · 产业带余料撮合员`：检索 `data/Scrap_Inventory.csv`，匹配周边 3km 内可套切的闲置余料并计算立省比例与金额。
3. **Argon 工业风三分栏工作台 (`app.py`)**：
   - **顶部通栏**：展示项目名称、戴南今日 304/316L/201/2205 实时基准价与下差系数看板。
   - **左栏（询盘输入与演示剧本区）**：支持上传图纸或从下拉框选择 `data/Test_Images/TP-001.png ~ TP-015.png` 并预览图纸；提供【剧本1：304常规垫板极速报价(TP-002)】【剧本2：手绘草图漏标厚度追问(TP-015)】【剧本3：316L法兰余料拼单立省25%(TP-001)】三个一键演示按钮。
   - **中栏（多智能体协同透明舱）**：动态展示 Agent 1 -> Agent 2 -> Agent 3 思考链卡片；当触发 `NEED_INFO` 时弹出微信追问话术复制框与“快速补填厚度(mm)”输入框，补填后一键接续核算。
   - **右栏（双轨报价单与余料拼单交付区）**：并排展示方案A/方案B价格大卡片、材料利用率进度条、绿色高亮的“跨厂余料拼单省钱卡片”与“内孔圆芯余料回血卡片”，底部提供一键导出正式报价单（HTML/CSV）按钮。
